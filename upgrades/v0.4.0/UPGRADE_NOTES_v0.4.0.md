# Finance OS · BankSalad v0.4.0 — Low-Touch Classification Upgrade

## 실제 원장 분석
- Finance OS `01_거래원장`: 총 25,225 데이터행 확인.
- 최근 학습구간 2024-01-01~현재: 4,464행.
- 그중 확정 분류 4,370행.
- 안전조건(최근 사용 + 분류 일관성 98% 이상 + 다의 merchant 제외)을 통과한 exact merchant 53개.
- merchant+금액 반복규칙 40개.
- 2026-07 과거 정제본은 205건 중 검토 54건이었으므로 과거 방식의 검토 비율이 높았음.

## 이번 업그레이드
1. 모든 1원 거래를 인증 노이즈로 자동 제외.
2. 개인명 양(+) 이체를 기본 `정산/일반 정산회수`로 자동확정.
3. ±7일 최근 지출과 정산입금을 날짜·금액·분할비율·카테고리로 점수화.
4. 82점 이상은 자동 상계. N:1 정산 지원.
5. 상계액을 원지출의 소비지출액에서 차감하여 최종 개인부담만 소비로 인식.
6. 사용자 확인 merchant와 명시적 업종 키워드를 우선 적용.
7. 원장 반복 패턴 53+40개를 sidecar 규칙으로 적용.
8. 검토 UI는 자유텍스트를 폐기하고 종속 dropdown + 추천값 + 학습체크로 전환.

## 현재 검토 큐에 대한 예상
- 이*환 입금 → 정산 자동확정 + 인접 지출 상계 후보.
- 키움 1원 2건 → 삭제/제외.
- 공공기관 4,000 → 수영장, `여행·여가·문화/운동·레저`.
- 정도진흥기업(주)강서점 → 발산역 역전할머니맥주, `술·사교/술·유흥`.
- 이편한세상치과의원 → `의료·건강/병원·약국`.
- 청담헤어 → `의복·미용/미용`.
- 쿠팡이츠 → `식비/배달`.
- 후불하이패스 → `교통·차량/통행료`.
- 서울도시가스 → `주거·공과금/공과금`.
- 맛자랑포차 → 포차 키워드로 `술·사교/술·유흥` 자동확정.
- 쿠팡_쿠페이 → merchant만으로 품목을 구분할 수 없으므로 계속 검토 유지.

즉 현재 예시 큐에서는 실질적으로 쿠팡 계열처럼 상세 품목이 없는 다의 merchant 위주만 사람이 보게 하는 방향이다.
